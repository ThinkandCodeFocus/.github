## Comment on travaille

> Chez nous, un projet ne se juge pas au premier commit mais à la facilité avec laquelle un nouveau développeur reprend le code six mois plus tard.

- **Revue de code systématique** — les branches principales sont protégées, toute modification passe par une pull request approuvée.
- **Conventions partagées** — nommage de branches, format de commits et style de code décrits dans notre [guide de contribution](https://github.com/ThinkandCodeFocus/.github/blob/main/CONTRIBUTING.md).
- **Accès par équipe** — les droits sont attribués par équipe (frontend, backend, mobile, devops), jamais au cas par cas.
- **Aucun secret dans le code** — clés et identifiants passent exclusivement par des variables d'environnement.
- **Sécurité prise au sérieux** — les vulnérabilités se signalent en privé, voir notre [politique de sécurité](https://github.com/ThinkandCodeFocus/.github/blob/main/SECURITY.md).
